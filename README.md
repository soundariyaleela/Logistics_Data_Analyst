# Logistics_Data_Analyst

Scenario and KPIs: an online retailer ("DataCo Global") with late deliveries, unprofitable orders and unstable demand. It uses five KPIs: on-time delivery rate, average delay, loss-making order rate, profit margin and forecast accuracy (MAPE).

Research: the public DataCo Smart Supply Chain dataset (Mendeley Data and Kaggle), plus the World Bank Logistics Performance Index, weather and holiday data, and OpenStreetMap as optional extras. It also covers what published analyses say about cleaning, class imbalance and target leakage.

Methods: classification for late-delivery risk, regression and time series for demand forecasting, clustering for regions, and linear optimization for shipping-mode choice.

Roadmap: a six-phase plan with timing, validation approach and a risk table.

Code: eight Python listings covering cleaning, KPIs, exploratory analysis, the classifier, forecasting with safety stock, clustering, optimization and a pipeline skeleton. The optimization listing uses placeholder cost and capacity values that you would replace with real estimates.

Outcomes and conclusion: a table linking each analysis to the decision it supports, then a short conclusion and references.
